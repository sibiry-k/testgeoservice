# testgeoservice
Тестовое задание для стажировки в компании Antipoff Group

## Запуск проекта в контейнерах

1. Клонировать содержимое репозитория с github.
2. Создать и заполнить файл .env по примеру env.example
3. Из корневного каталога запусить контейнеры командой 'docker compose up --build'
4. Перейти по адресу: http://localhost:8000/docs
5. В разделе auth зарегистрировать пользователя по ссылке /auth/register
6. Авторизоваться
7. В разделе Local:
   - проверить, что сервер запущен по ссылке http://localhost:8000/ping
   - сделать POST-запрос по ссылке http://localhost:8000/query, указав необходимые данные
   - запросить историю всех запросов по ссылке http://localhost:8000/history
   - запросить историю запроса по кадастровому номеру: http://localhost:8000/history/{cad_num}
